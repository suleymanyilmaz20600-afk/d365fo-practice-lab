# D365FO Finance + SCM + X++ Practice Lab — Phase 4

Bu repo, D365FO Finance + SCM + X++ eğitim kitabına paralel ilerleyen browser tabanlı çalışma ortamıdır.

## Tamamlanan fazlar
- **Faz 1:** D365FO benzeri shell, modül menüleri, Finance/SCM ekranları.
- **Faz 2:** GL journal validate/post/voucher; AP/AR invoice-payment-settlement; posting profile, VAT, exchange-rate ve FX farkı pratikleri.
- **Faz 2.1:** X++ Practice Center — iş bağlamı / sorun / istek / soru / başarı kriterleri / ipuçları / referans yaklaşım.
- **Faz 3:** Production Troubleshooting Lab — 10 öğretici incident senaryosu, evidence-first diagnosis, standard fix, validation, mentor review ve incident notları.
- **Faz 4:** SCM Junior Transaction Engine — product master, PO confirmation, partial/full product receipt, vendor invoice, physical/financial on-hand, transfer, counting, reservation, packing slip, sales invoice, simplified planning/firming ve inventory costing/Finance bridge.

## Faz 4 çalışma zinciri
1. Released product + inventory dimensions
2. Purchase order create/confirm
3. Partial/full product receipt
4. Vendor invoice financial update
5. Physical / reserved / available / financial on-hand
6. Warehouse transfer
7. Counting adjustment
8. Sales reservation + packing slip
9. Customer invoice + Finance bridge
10. Master planning simplified run
11. Planned order approve + firm
12. Costing + physical/financial posting timeline

> Not: Faz 4 muhasebe hesaplarını öğretim amacıyla sadeleştirir. Gerçek D365FO ledger posting sonucu item group inventory posting setup, parameters ve cost model'e göre değişir.
